# Icons8 Fluency assets

These local PNGs are downloaded from the official Icons8 image CDN and used as local UI assets.

- Source collection: [Icons8 Fluency / Windows 11 Color icons](https://icons8.com/icons/set/camera--style-fluency)
- Asset host: [Icons8 image CDN](https://img.icons8.com/fluency/96/camera.png)
- License guidance: [Icons8 license](https://icons8.com/license)
- License terms: [Universal Multimedia Licensing Agreement](https://intercom.help/icons8-7fb7577e8170/en/articles/5534926-universal-multimedia-licensing-agreement-for-icons8)

Icons8's free-use guidance states that websites and apps should link to `https://icons8.com/` on pages using the content (a footer link is acceptable when most pages use it). The project must retain that attribution in the deployed website. These files are not presented as MIT, Apache-2.0, or public-domain assets.

## Slug mappings

The requested semantic names use the nearest verified Fluency slug where the exact slug was unavailable:

- `folder` -> `folder-invoices`
- `folder-open` -> `opened-folder`
- `users` -> `group`
- `eye` -> `visible`
- `eye-off` -> `invisible`
- `close` -> `cancel`
- `warning` -> `high-priority`
- `game-controller` -> `console`
- `maximize` -> `full-screen`
- `minimize` -> `minimize-window`
- `volume` -> `speaker`
- `heart` -> `like`
- `party` -> `champagne`
- `sparkles` -> `sparkling`
- `torii` -> `torii`
- `archive` -> `archive`
- `scroll` -> `scroll`
- `fortune-teller` -> `fortune-teller`

All other filenames retain their requested slug. The PNGs are bundled locally; the runtime does not hotlink Icons8.
